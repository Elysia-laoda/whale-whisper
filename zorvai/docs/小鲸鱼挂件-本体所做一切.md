# 🐋 小鲸鱼挂件 · 本体所做一切（总览说明书）

**生成** 2026-10-11 · **宿主** ZorvAI (com.ai.assistance.quro) · **设备** vivo V2156FA / Android 11 / aarch64
**上游** github.com/Elysia-laoda/whale-whisper (MIT) · 本包 = 第三个移植版（ZorvAI 手机端）

---

## 一、这是什么（一句话）

给 ZorvAI 挂一只**常驻屏幕的小鲸鱼** 🐋：任务跑得正欢时，点它一下，
AI 立刻停下来问你「**有什么要补充的吗？**」——不打断、不等候。

---

## 二、本体（APK: com.zorv.whale）做了什么

| # | 行为 | 实现 | 边界 |
|---|---|---|---|
| 1 | 在屏幕上常驻一只小鲸鱼 | 前台服务 `OverlayService` + `WindowManager` `TYPE_APPLICATION_OVERLAY` | 仅显示自己这一个悬浮图标 |
| 2 | 可拖动、自动贴边、位置记忆 | `onTouch` 位移阈值 8dp + `SharedPreferences` 持久化 | 拖动时不触发点击 |
| 3 | 点一下 → 投递「补充提示」事件 | 写 JSON 到公共区 `pending.json`（三级回退） | **只写这一个文件** |
| 4 | 启动/停止/权限引导 | `MainActivity` 三个按钮 | 无后台任务、无定时器 |
| 5 | 开机自启（可选） | `BootReceiver` | 可关 |
| 6 | 前台通知（保活） | `IMPORTANCE_MIN` 静默通知 | 可忽略 |

**它不做什么（重要）**：
- ❌ 不联网、不上传任何数据
- ❌ 不读通讯录/短信/位置/相册
- ❌ 不监听键盘、不截屏、不无障碍
- ❌ 不修改其它 App 的数据（只往一个约定文件写事件）

**权限清单**：`SYSTEM_ALERT_WINDOW`（悬浮窗）、`FOREGROUND_SERVICE(+_SPECIAL_USE)`、`POST_NOTIFICATIONS`、`RECEIVE_BOOT_COMPLETED`、`WAKE_LOCK`、`MANAGE_EXTERNAL_STORAGE`（可选，用于直写工作区）

## 三、事件协议（本体 ↔ ZorvAI 的唯一接口）

**写入点（按优先级）**
1. `/sdcard/Android/data/com.ai.assistance.quro/files/QuroWorkspace/whale-whisper/state/pending.json`（需 MANAGE_EXTERNAL_STORAGE）
2. `/sdcard/qshare/whale/pending.json` ← **默认**
3. `/sdcard/Download/whale/pending.json`（兜底）

**格式**
```json
{
  "id": "w1791698791960",
  "ts": 1791698791960,
  "source": "android-overlay",
  "state": "pending",
  "note": "用户点击了小鲸鱼"
}
```
多事件时包在 `{"events":[…],"acked":[],"mute":false}` 里。

**去重**：ZorvAI 侧 `whale_ack(id)` 标记已处理，同一 id 不重复提问。

## 四、ZorvAI 侧做了什么

| 层 | 文件 | 作用 |
|---|---|---|
| ToolPkg | `packages/whale/{manifest.json,index.js}` | 事件队列读写：`whale_pending` / `whale_ack` / `whale_simulate` / `whale_state` |
| 技能 | `skills/whale/{whale.skill.json,whale.prompt.txt}` | 行为铁律：每轮先搬运再检查；有事件立刻问；问完必须 ack |
| proot 桥 | `/usr/local/bin/whale-sync`、`whale-click` | 搬运（公共区→工作区）/ 模拟点击（联调） |

**为什么需要「桥」**：实测 ToolPkg 沙箱只能读写工作区（`canReadQshare:false`），够不着公共区；
而 APK（第三方 App）在 Android 11 下够不着 ZorvAI 的工作区。**proot 是唯一能同时访问两边的进程**。

```
[点击鲸鱼] → APK 写公共区 → whale-sync(proot) → 工作区队列 → whale_pending → AI 提问 → whale_ack
```

## 六、怎么用（用户手册）

| 我想… | 怎么做 |
|---|---|
| 任务中途补一句 | **点一下屏幕上的小鲸鱼** → AI 会问「有什么要补充的吗？」→ 直接说 |
| 暂时不想被问 | 对 AI 说「关掉挂件」→ `whale_state({mute:true})` |
| 恢复 | 对 AI 说「打开挂件」→ `whale_state({mute:false})` |
| 鲸鱼不见了 | 打开「小鲸鱼挂件」App → 点「② 启动挂件」 |
| 想彻底停掉 | App 里点「③ 停止挂件」 |

## 七、怎么复现（从零到跑通）

1. **装 APK**：`adb install zorv-whale-overlay.apk`
2. **开权限**：`adb shell appops set com.zorv.whale SYSTEM_ALERT_WINDOW allow`
3. **启动**：打开 App → 「② 启动挂件」→ 屏幕上出现鲸鱼
4. **ZorvAI 侧**：确保 `skills/whale/whale.skill.json` 已在「技能管理」启用
5. **验证**：点鲸鱼 → 对 AI 说「检查挂件事件」→ 应被问到「有什么要补充的吗？」

无 APK 时的联调：`whale-click "测试"` → `whale-sync` → 让 AI 检查。

## 九、已知限制

| 限制 | 影响 | 规避 |
|---|---|---|
| ToolPkg 读不到公共区 | 不能直接读 APK 写的事件 | 每轮跑 `whale-sync`（技能已内置） |
| 无 hook 挂载点（ZorvAI 无 PostToolUse 等） | 点击后不是"立即"打断，而是"下一轮/下次工具调用"时接住 | 轮首检查 + 可选定时轮询 |
| Android 11 分区存储 | 第三方 App 写不进工作区 | 默认走公共区 + proot 搬运 |
| vivo 后台冻结 | 鲸鱼可能被系统回收 | 前台服务 + 电池白名单 |
| 无障碍未连接 | 无法用截图做视觉复核 | 已用「服务在跑 + 真实点击事件」取证替代 |
